# Build notes

The current package uses Capacitor 8.5.1, which is the current stable 8.x package line at the time this project was prepared.

The GitHub workflow uses Node 22 and JDK 21. The native Android project is generated by `npx cap add android` and then built with its generated Gradle wrapper. This is safer than manually inventing an Android project and keeps Capacitor's native template aligned with the installed Capacitor version.

The workflow installs Android API 36 and Build Tools 36.0.0 using command-line SDK tooling, so Android Studio is not required on the developer's machine or in the CI workflow.
